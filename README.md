1. در پوشه‌ی `02_طرح_توسعه_یافته\build` ترمینال باز کنید
2. اجرای: `node build_docx.js`
3. خروجی در `..\سند_آمایش_استانی_طرح_توسعه_یافته.docx` ساخته می‌شود
