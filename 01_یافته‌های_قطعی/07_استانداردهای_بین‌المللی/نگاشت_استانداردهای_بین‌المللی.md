# یافته قطعی ۷ — نگاشت استانداردهای بین‌المللی

**وضعیت:** قطعی
**منبع:** خانواده A (بخش ۸، ماتریس‌های چهارگانه)

## چارچوب‌های مرجع

| چارچوب | کاربرد |
|---|---|
| ISO 37120 | شاخص‌های خدمات شهری و کیفیت زندگی |
| ISO 37122 | زیرساخت و خدمات شهری |
| ISO 37123 | محاسبه شاخص‌های ترکیبی شهری |
| UMF (UN) | چارچوب جهانی پایش شهری |
| SDG/UN | ۱۷ هدف، ۱۶۹ هدف فرعی |
| UN-Habitat CPI | شاخص شکوفایی شهر |
| World Bank WDI | داده‌های توسعه بین‌المللی (crosswalk) |
| GCIF / COFOG | طبقه‌بندی مالی/بودجه |
| ISO 19115 / 19139 / 19157 | متادیتای مکانی و SDI |
| OGC API | سرویس‌های نقشه |

## ماتریس‌های نگاشت

1. دامنه ← ISO37120/37122/37123 + UMF + SDG + WDI
2. شاخص‌های انتخابی ← SDG + UMF + ISO
3. crosswalk با WDI (نام/واحد/دوره)
4. فرایند نگهداری crosswalk (مالک + دوره بازنگری + نسخه)

> نکته: «SCI» در منابع ابهام‌آمیز است و به‌عنوان شاخصِ تعریف‌شده توسط صاحب کار (employer-defined) معالجه می‌شود، نه یک استاندارد جهانی ثابت.
