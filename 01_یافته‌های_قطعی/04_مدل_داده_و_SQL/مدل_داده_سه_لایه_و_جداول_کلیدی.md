# یافته قطعی ۴ — مدل داده سه‌لایه و جداول کلیدی

**وضعیت:** قطعی
**منابع:** خانواده A (بخش ۶، DDL کامل) · خانواده B (بخش ۷ + پیوست د)

## سه لایه مفهومی

1. **موجودیت فضایی (regions / geo_unit):** شناسه، والد، سطح، کد رسمی، هندسه، بازه اعتبار.
2. **تعریف شاخص (indicators):** کد، دامنه/خوشه، واحد، صورت/مخرج، روش تجمیع، جهت، مالک، طبقه رازداری، نسخه.
3. **مشاهده (observations / fact_observation):** شاخص × مکان × دوره × مقدار + صورت/مخرج + طبقه داده + منبع + کیفیت.

## شیمی شش‌گانه منطقی (PostgreSQL + PostGIS)

`raw` · `ref` · `core` · `mart` · `api` · `audit`

## جداول اصلی (از DDL خانواده A)

- `ref.geo_unit` — geo_id، geo_type (country…parcel, zone)، stable_code، geom (4326)، بازه‌های dual
- `ref.geo_relation` — parent/child + relation_type + بازه اعتبار (کلید ترکیبی)
- `ref.dim_time` — period_type (day/month/quarter/year/census)
- `ref.indicator` — aggregation، direction (higher/lower_better, target_range, descriptive)
- `core.fact_observation` — value_numeric NUMERIC(24,8)، numerator_val/denominator_val، data_class، quality_score، uncertainty_low/high، UNIQUE(indicator, geo, period, recorded_at)
- `core.fact_public_opinion` — geo_precision/confidence، polarity، urgency، model_version، content_hash، privacy_class

## جداول D12 (از پیوست د خانواده B)

- `facilities` — facility_id، facility_type (Enum ۶۰+)، operational_level، capacity (JSONB)، geometry، sensitivity، quality_flag
- `service_area` / `flows` — پوشش و جریان کالا/خدمت
- `spatial_validation_rules` — قواعد اعتبارسنجی مکانی (فاصله تا لایه هدف)

## مدل زمان دومرگ و SCD

ستون‌های `valid_from/valid_to` + `recorded_from/recorded_to`؛ SCD Type 2 برای تاریخچه؛ lineage و audit_log برای ردیابی.
